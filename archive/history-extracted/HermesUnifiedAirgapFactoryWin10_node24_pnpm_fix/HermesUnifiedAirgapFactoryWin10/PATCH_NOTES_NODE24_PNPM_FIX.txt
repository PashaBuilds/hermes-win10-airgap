Fixed Hermes v0.16 Desktop build Node engine mismatch.
Previous factory used portable Node 22. Hermes v0.16 Desktop dependency @icons-pack/react-simple-icons requires Node >=24 and pnpm >=10.
This package now resolves/downloads portable Node.js 24.x Windows x64 and installs pnpm@10 into a bundle-local npm prefix before running `hermes desktop --build-only`.
